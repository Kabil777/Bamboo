# Code Snippet Examples

Below are examples of code snippets in various languages. Each section uses a heading and includes a brief description in paragraph form.

---

## Java Example

This is a simple Java class that prints "Hello, World!" to the console.

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

---

## Go Example

This Go program prints "Hello, Go!" to the standard output.

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, Go!")
}
```

## JavaScript Example

This JavaScript function returns the sum of two numbers.

```js
function add(a, b) {
    return a + b;
}
console.log(add(2, 3));
```

---

## TypeScript Example

A TypeScript function that adds two numbers with type annotations.

```typescript
function add(a: number, b: number): number {
    return a + b;
}
console.log(add(5, 7));
```
